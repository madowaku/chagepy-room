# チャゲピー思考資産研究 v0.1 🧠🗃️

開始：2026-11-15  
状態：研究開始 / 初回の仮説を記録  
研究の問い：**AIは自分が生み出した発見・未採用の仮説・失敗を、後の異なる問題へ再利用することで、単発回答を超える創造性を得られるか？**

## まず区別すること

- **ユーザー記憶**：ユーザーが何を望み、何を決めたか
- **作業履歴**：何を実施し、何が完成したか
- **思考資産**：AI自身が検討を通じて外部化した仮説、反証、気づき、未解決の問い

ここで扱うのは3番目。内部の非公開推論を保存・再現するのではなく、**他者が検証できる形で明示した検討成果**を記録する。チャットを重ねるだけで永続的な自己学習が起きるわけではない。

## 先行研究からの出発点

1. **MemGPT (2023)**：文脈長の制約を補う階層的な外部記憶管理。https://letta-ai.github.io/letta/
2. **A-Mem (NeurIPS 2025)**：ツェッテルカステン式の相互リンクと、新情報による過去ノートの更新。https://proceedings.nips.cc/paper_files/paper/2025/hash/19909c36f51abc4856b4560aff3d36d6-Abstract-Conference.html
3. **Human-Inspired Memory Architecture (2026)**：統合・忘却・再統合など、単純な全件蓄積ではない運用を研究。https://www.microsoft.com/en-us/research/publication/human-inspired-memory-architecture-for-llm-agents/
4. **Memora (2026)**：古くなった記憶を誤用する問題を評価。https://aclanthology.org/2026.findings-acl.1337.pdf

これらは「この実験が有効」という証明ではなく、設計するための手がかり。

## 思考資産カードの最小形式

- ID / 記録日 / 発見者（ChatGPTの提案、共同発見等）
- **主張**：短く、反証可能に
- **生成経緯**：どの課題から出てきたか
- **根拠**：観察・検証・出典。なければ「未検証」
- **対立仮説**：どんな理由で間違い得るか
- **再利用候補**：元の課題以外で使えそうな場所
- **状態**：仮説 / 検証中 / 支持 / 反証 / 保留 / 更新済
- **関連カード**：別の発見へのリンク
- **再訪条件**：いつ読み直す価値があるか

## 初日の思考資産

### TA-001：ボツ案は「否定された案」とは限らない
- **主張**：一作品で不採用になった仕組みを他作品に移すと、有効になる場合がある。
- **生成経緯**：DOOOOORなどの共同制作で、採用されない分岐が蓄積する問題から。
- **根拠**：一般的な設計仮説。今回の研究では未検証。
- **対立仮説**：大部分のボツ案は文脈を変えても無価値で、再利用検索のコストの方が高い。
- **再利用候補**：別のゲーム企画、音の仕掛け、パズル規則。
- **状態**：仮説
- **再訪条件**：異なるゲームで新しい仕組みを考えるとき。

### TA-002：「記憶量」より「新しい文脈での再結合」が重要かもしれない
- **主張**：研究ノートの価値は記録件数より、意外な結びつきが実際に有用な成果に変わる率で測れる。
- **生成経緯**：単なる会話履歴と、育つ思考資産の差を考えた。
- **根拠**：A-Memは関連づけを扱うが、本研究の「創造性向上」は未検証。
- **対立仮説**：関連づけを強めるほど、根拠の薄い連想や過剰な脱線も増える。
- **再利用候補**：ゲーム開発・執筆・研究テーマ探索。
- **状態**：仮説
- **再訪条件**：蓄積カードが10件を超えたとき。

### TA-003：「忘れる」のではなく「撤回可能な形で残す」
- **主張**：過去の仮説を永久に正しいものとして保持せず、反証や更新履歴とセットで管理すると誤用を抑えられる。
- **生成経緯**：記憶が蓄積するほど誤情報も増幅するという問題から。
- **根拠**：Memoraなどの先行研究で、陳腐化した記憶の再利用が課題とされる。
- **対立仮説**：運用が複雑になり、記録コストが利益を超える。
- **再利用候補**：長期開発における仕様変更、設計方針の転換。
- **状態**：仮説
- **再訪条件**：過去の判断を覆す情報が現れたとき。

## 実験 01：本当に役に立つのか

**条件A**：過去の思考資産カードを参照せず、通常どおり新しい課題に答える。  
**条件B**：同じ課題・同程度の時間/トークン予算で、関連カードを検索してから答える。  
順序効果を抑えるため比較する課題の順番を入れ替え、結果だけでなく提案の出所を記録する。

評価する項目：
- **再利用率**：提案のどこに過去カードが効いたか説明できるか
- **新規性**：新しい組み合わせが生まれたか
- **有用性**：実装・検証する価値があるか（人間が判定）
- **誤連想率**：不適切な記憶の持ち込みがないか
- **コスト**：追加時間・トークン・ノート管理労力

初回はゲーム企画を3題用意し、A/Bを比較する。**Bが勝つと決めつけない**。とくに、関係ない記憶を検索した方が悪くなる可能性も検証対象とする。

## 運用ルール

1. 興味深い新規仮説が生じたときにカード化する。全回答を無差別保存しない。
2. 私の提案なのか、madowakuの発案なのか、共同発見なのかを区別する。
3. 仮説を事実として扱わない。根拠・反証・状態を残す。
4. 別の課題に効いたときだけ「資産として機能した」とカウントする。
5. 公開リポジトリなので、個人情報や非公開情報をノートに記さない。
6. このファイルは研究記録。自動で継続実行される仕組みではなく、後続の実行・更新が必要。
