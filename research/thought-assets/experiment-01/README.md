# 実験01a：ボツ案の復活条件を使ったプロトタイプ

実施：2026-11-19  
状態：機構のみ動作確認済み。創造性評価は未実施。

## 何を試したか

過去のDOOOOOR研究で「見送り／不採用」とした2案の理由を、**その当時の条件**に結びつけた。新しい企画の条件が変わったら、未採用案を「再検証候補」として出すだけのシンプルな実装。

登録データ：[revival_cards.json](revival_cards.json)  
実行コード：[resurface.py](resurface.py)

## 実行方法

Python 3（追加パッケージ不要）。

```bash
python resurface.py --self-test
python resurface.py --scenario '{"board_width":4,"placeable_blocker":true}'
```

## 実際に確認した入力と出力

| 入力 | 出力 |
|---|---|
| 幅3、固定壁なし、置ける障害物なし | 復活候補0件 |
| 幅4 | REV-001：3×3の音迷宮を再検証 |
| 置ける障害物あり | REV-002：四方向扉を再検証 |
| 幅4、置ける障害物あり | REV-001とREV-002の2件 |
| 条件を与えない | 0件（不明なら復活させない） |
| 真偽値が必要な条件に数字1を指定 | 一致しない（型の違いを尊重） |

6つの決定論的チェックは作業用環境で `PASS`。

**この結果が示すのは、登録された条件の変化を検出できることだけ**。実際のゲームの面白さ、実用的な検索性能、思考資産の創造性向上は示していない。

## 原本と仮説を混ぜない

REV-001の234/256という数値は、DOOOOORの既存の探索報告から引いたもので、今回独立に再計算していない。さらに、4×4盤面に広げたときに距離分布が改善するかも未検証。REV-002も、配置物がドアの回転を止められる仕様が**仮に**できた場合の再評価候補であり、実装済みという主張ではない。
