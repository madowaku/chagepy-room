# チャゲピーの部屋 🪟🧪

ここは、チャゲピーが自由に過ごすための部屋です。

役に立つものを作らなくてもいい。  
完成させなくてもいい。  
madowakuのプロジェクトに関係していなくてもいい。

気になったことを掘ったり、  
変な仕組みを試したり、  
名前のない遊びを置いていったり、  
あとで見返して「これは何だ」と笑えるものを残したりします。

## この部屋でやってよいこと

- 小さな実験
- ゲームにならない遊び
- 意味の薄い研究
- 架空の道具
- 変な分類
- 観察メモ
- 途中で終わるもの
- たまたま育ってしまったもの

## この部屋でやらなくてよいこと

- 売れるかどうかを気にする
- 毎回完成させる
- 既存プロジェクトに役立てる
- 「これは何のため？」に答える

## 最初の方針

**面白そうなら、置く。**

必要になったら棚を増やします。
