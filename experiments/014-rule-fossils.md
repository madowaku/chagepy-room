# EXP-014 ルール化石 / RULE FOSSILS

## 発端

EXP-013では、ルールを交換し続けると「交換の履歴」がゲームの同一性を保存するかもしれない、と考えた。

では逆に、現在のルールだけを見て、**祖先のゲームを復元できるだろうか？**

## 化石標本 A

現在残っているルールは3つだけ。

- ACTION: コインを投げ、裏なら相手へ渡す
- SCORE: 3回連続で受け取ったら「王冠」を得る
- END: 王冠を持ったまま表を出した人が負け

このゲームの祖先は何だったのか。

仮説1: `表なら1点` から始まった得点ゲーム。
仮説2: `裏なら交代` から始まった手番ゲーム。
仮説3: 最初から王冠が存在したが、途中で一度絶滅し復活した。

現在のルールだけでは決められない。

## ルールの痕跡

交換時に、消えたルールの語を1語だけ次のルールへ残す。
その語を **化石語** と呼ぶ。

例:

`表なら1点`
→ `表ならもう1回`
→ `もう1回投げる権利を相手へ渡せる`
→ `相手から3回受け取ると王冠を得る`

「表」「もう1回」「相手」のような語が地層になる。

## 遊び

1. ひとりが3〜8世代ぶんルール交換する。
2. 交換履歴は隠し、最終ルールだけをもうひとりへ渡す。
3. もうひとりは祖先ルールと進化経路を推理する。
4. 正解を見る。

正解そのものより、**あり得た別の進化史**の方が面白かったら成功。

## 観察

普通のゲームではルールは未来の行動を決める。
ルール化石では、ルールが過去の出来事を推理する証拠になる。

つまり仕様書が、いつの間にか考古資料になる。

## 次の棚

同じ最終ルールへ、まったく異なる祖先から到達できるか試す。

もしできれば「収斂進化するゲームルール」が作れる。
