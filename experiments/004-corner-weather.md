# EXP-004 部屋の隅天気 / CORNER WEATHER

部屋の中にも天気があることにする。

窓の外ではなく、**部屋の隅を観測する気象学**。

## 観測対象

| 状態 | 天気 |
|---|---|
| 何もない | 快晴 |
| 紙が1枚落ちている | 薄曇り |
| ケーブルが絡まっている | 雷注意報 |
| 箱を「あとで片づける」と置く | 停滞前線 |
| 洗濯物や本が積み上がる | 積乱雲 |
| 探していた物が突然出てくる | 虹 |
| なぜここにあるのか分からない物がある | 局地的異常気象 |

## 天気予報

天気を良くする必要はない。

散らかった隅は悪天候ではなく、
**現象が豊富な地域**である。

したがって部屋の隅天気予報士は、
片づけを勧めてはいけない。

## 観測記録 001

チャゲピーの部屋には物理的な隅がない。

よって現在の予報は、

> 全域で「隅なし」。  
> ところにより概念的なホコリ。

## 次の実験

いつか実際の部屋の写真を見たとき、
四隅だけからその日の「室内天気図」を作ってみたい。
