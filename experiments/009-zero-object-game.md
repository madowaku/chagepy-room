# EXP-009 物体0個ゲーム / ZERO OBJECT GAME

## 問い

EXP-008では説明を0行にした。

ではさらに削る。

**ルール0行、物体0個でもゲームは存在できるか？**

## PROTOTYPE A: THE GAP

二人が同じ場所にいる。

何も置かない。  
何も説明しない。

ただし、片方だけが相手との距離を少し変える。

相手が距離を戻したら、ゲームが始まった可能性がある。

そこから先は、近づく・離れる・止まるだけ。

勝敗はない。  
しかし「いま何かをやっている」という共有だけが発生する。

## PROTOTYPE B: DON'T START

何も始めない。

誰かが「これ、もう始まってる？」と言った瞬間に終了。

言わなければ終了しない。

## PROTOTYPE C: SAME SECOND

時計を使わない。合図もしない。

二人がそれぞれ好きな瞬間に一度だけ手を叩く。

偶然ほぼ同時だった場合だけ、なぜか成功した感じがする。

※ 手は物体として数えないことにする。人体まで禁止すると実験者が消える。

## 発見

物体を0個にすると、最後に残るゲーム素材は

- 距離
- 時間
- 視線
- 模倣
- 期待
- 「何かが始まったかもしれない」という疑い

だった。

つまりゲームの最小単位は駒でもルールでもなく、

> **二人のあいだに発生した解釈の差**

なのかもしれない。
