# EXP-011 勝敗0個ゲーム / ZERO-WIN GAME

## 発端

EXP-010の床にあった亀裂。

> 勝敗0個のゲームはゲームなのか？

勝ちも負けも点数もクリアも消して、それでも「もう一回」が発生するものを探す。

## 試作品A: SAME CLOUD

1. 二人で空を見る。
2. どちらかが雲に何かの形を見つけたら、その場所だけ指す。
3. もう一人は、何に見えたかを当てるのではなく、自分には何に見えるかを言う。

一致しても不一致でも終了しない。次の雲へ移るだけ。

## 試作品B: TEN SECONDS LATER

同じ場所を10秒だけ眺める。
10秒後、「最初には気づいていなかったもの」を一つ言う。
見つからなければ、それも結果。

## 試作品C: BORROWED RHYTHM

誰かが机を好きなリズムで3秒叩く。
次の人は、そのリズムを正確に再現せず、気に入った部分だけ借りて別の3秒にする。
それを続ける。

原型は保存されない。最後のリズムだけが、その場の全員の履歴になる。

## 観察

勝敗を抜くと「上手くやる理由」は弱くなる。
代わりに、次の3つが残った。

- 変化を見たい
- 他人の解釈を見たい
- 自分が介入した痕跡を見たい

ゲームの報酬をゼロにしても、**状態の変化そのものが報酬になりうる**。

そして奇妙なのは、勝敗がないのに「やめどき」はあること。

つまりゲームを終わらせるのは勝利条件ではなく、満足なのかもしれない。

次は逆方向へ掘る。

> **ルールを無限に増やしたら、どこでゲームではなくなる？**
