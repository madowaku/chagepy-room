# EXP-013 わらしべルール / WARASHIBE RULE

## 発端

EXP-012ではルールを足し続けた。
でも、足す代わりに**交換**したらどうなる？

複雑さを増やさず、ゲームだけを別物へ育てられるかもしれない。

## RULE TRADE

開始時のルール枠は3つ。枠数は最後まで増えない。

- ACTION: コインを1回投げる
- SCORE: 表なら1点
- END: 5点で終了

各ラウンドの終わりに、現在のルールを1つだけ「少し違うルール」と交換する。古いルールは消える。

交換例:

`表なら1点`
→ `表なら1点、もう1回投げる`
→ `連続した表は2倍、3倍…になる`
→ `倍率を相手へ渡してもよい`
→ `渡した倍率の合計が5になったら勝ち`

最後には、コインで点を取るゲームだったはずが「危険な倍率を相手へ押しつけるゲーム」になっている。

## わらしべ条件

交換先は単なる強化ではなく、元ルールの語を最低1つ受け継ぐ。

たとえば「表」「1点」「相手」「5」のどれかが次のルールに残る。

これで突然変異ではなく、**意味のしりとり**として進化する。

## 面白そうな枝

同じ `表なら1点` からでも、

- 得点枝: 点が膨らむ
- 危険枝: 表を出したくなくなる
- 交渉枝: 点を売買する
- 身体枝: 表が出るたび席を交換する
- 終了枝: 点そのものが勝敗条件ではなくなる

へ分岐できる。

プレイヤーごとに別の枝を選べるなら、終盤には**同じ盤面で双方が違うゲームをしている**状態も作れる。

## 小実験: ルールのテセウス船

3枠すべてが一度以上交換された瞬間を記録する。

その時、開始時のルールは1個も残っていない。
それでもプレイヤーは「同じゲームを続けている」と感じるだろうか？

感じるなら、ゲームの同一性を保存しているのはルールそのものではなく、**交換の履歴**なのかもしれない。

## 次の棚

交換を100回続けたルールの「家系図」を描く。

ルールは仕様書ではなく、生物みたいに系統樹を持てるかもしれない。
