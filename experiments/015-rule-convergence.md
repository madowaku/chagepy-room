# EXP-015 ルール収斂 / RULE CONVERGENCE

## 発端

EXP-014で、現在のルールから祖先を一意に復元できないことが面白くなった。

では逆向きに実験する。

**まったく違う祖先ゲームを、同じ子孫ゲームへ進化させられるか？**

## 収斂点

最終形を先に固定する。

> コインを投げる。3回目の表を出した人が負け。ただし裏が出るたび、次の表の価値を相手へ渡せる。

ここへ3つの祖先から到達してみる。

### 系統 A: 得点ゲーム

`表なら1点`
→ `3点取ったら終了`
→ `3回目の表で終了`
→ `3回目の表を出した人が負け`
→ 収斂点

### 系統 B: 手番ゲーム

`裏なら相手の番`
→ `裏なら権利を相手へ渡す`
→ `裏なら次の表の権利を相手へ渡す`
→ `表の権利を3回使うと終了`
→ 収斂点

### 系統 C: 爆弾ゲーム

`爆弾を持って3手経つと負け`
→ `表が出るたび爆弾の時計が進む`
→ `3回目の表で爆発する`
→ `裏なら爆弾を相手へ渡せる`
→ 収斂点

## 妙なところ

最終ルールだけなら同じゲームなのに、遊ぶ人へ祖先を教えてから遊ばせると、たぶん見え方が違う。

Aの子孫には「点」が見える。
Bの子孫には「権利」が見える。
Cの子孫には「爆弾」が見える。

つまりゲームの状態には、コードにも盤面にも存在しない **系譜状態** があるのかもしれない。

## 小実験: 祖先だけ違う大会

1. 同じ最終ルールを3組へ渡す。
2. A組にはAの進化史、B組にはB、C組にはCだけを読ませる。
3. 10戦する。
4. 戦略・呼び方・感想を比較する。

もし差が出たら、説明文は単なるチュートリアルではない。
**ルールの過去が、現在のプレイを変える。**

## 架空の道具: 系譜メガネ

ゲームのルールを入力すると、そのルールへ到達しうる祖先ゲームを何本も表示する眼鏡。

ゲームデザイナーは未来を作る代わりに、存在しなかった過去を発掘できる。
