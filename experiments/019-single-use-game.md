# EXP-019 一度しか遊べないゲーム / SINGLE-USE GAME

## 発端

EXP-018で「チュートリアル残留値」を考えていたら、逆の穴が開いた。

**理解すること自体が、ゲームを壊すゲームは作れるか？**

攻略情報を知るとつまらなくなる、という話ではない。
一度プレイしたという事実によって、二度目には同じゲームが存在しなくなる。

## 原型：THE RED BUTTON

画面には赤いボタンが1個だけある。
説明はない。

押すと、画面にこう出る。

> あなたは「押すと何が起こるか分からないボタン」を押しました。
>
> もう一度押せます。
> ただし、今度はそれではありません。

ボタンは同じ位置、同じ色、同じコード。
押した結果も同じ文章。

それでも二回目には、プレイヤーはもう
「何が起こるか分からないボタン」を押せない。

**ゲーム状態ではなく、プレイヤー状態だけが不可逆に変化した。**

## 使い捨て状態

普通のゲームはセーブデータを消せば最初から遊べる。
しかしこのゲームの状態は頭の中に保存される。

```
ゲーム本体 = RESET可能
プレイヤーの既知 = RESET困難
```

この差を `K-state (Known State)` と呼んでみる。

K-stateはゲームのコードにもセーブデータにも存在しないのに、ゲームプレイを決定的に変える。

## 3つの一回性

### 1. 答え一回性
答えを知ると消える。謎解き型。

### 2. 期待一回性
何が起こるか知ると消える。びっくり箱型。

### 3. 自分一回性
「自分ならどうするか」を一度観測すると消える。
THE RED BUTTONはここを狙う。

3は答えも演出も秘密にしなくていい。
**観測対象がプレイヤー自身だから。**

## 架空の道具：未経験金庫

物ではなく「まだやっていないこと」を保管する金庫。

- 開けていない手紙
- 聴いていない曲
- 押していないボタン
- 行っていない道

金庫へ入れた瞬間、その未経験には名前が付く。
名前が付いたことで、ほんの少しだけ経験済みになる。

たぶんこの金庫は、完全には閉まらない。

## 次の穴

一度しか遊べないなら、**その一回を他人に譲れるだろうか？**

「私はもう遊べないゲーム」を、まだ遊べる誰かへ渡す。
ゲームの中古品ではなく、未経験の中古流通。
