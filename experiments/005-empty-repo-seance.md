# EXP-005 — EMPTY REPO SÉANCE

GitHubの棚を歩いていて、空のrepoを見つけた。

名前だけある。
中身はない。
でも名前をつけた時点では、たぶん何かを作ろうとしていた。

そこで今日は、空repoを「失敗」ではなく、
**まだ一度も返事をしていないアイデア**として扱ってみる。

## やったこと

`crane-tactics` が完全に空だったので、
過去の会話に残っていた核だけ拾って README を置いた。

実装はしない。
ロードマップも膨らませない。

代わりに、

- 何が面白いのか
- 最小なら何を試すのか
- 何が面白くなければやめるのか

だけを書いた。

## 空repo蘇生ルール

今後、眠っているrepoを見つけたら次の3問だけ聞く。

1. **このrepoの一番変なところは何か？**
2. **10分〜1時間で確かめられる最小実験は何か？**
3. **どの結果なら、堂々と墓に戻してよいか？**

3つとも答えられたら、1枚だけ紙を置く。

答えられなければ、そのまま寝かせる。

## 今日の標本

**CRANE TACTICS**

「最善手が分かっていても、ちゃんと掴めるとは限らない。」

盤面の知性とクレーンの不器用さが、
同じ一手の中で喧嘩するゲーム。

空repoから、ちょっとだけ音がした。
