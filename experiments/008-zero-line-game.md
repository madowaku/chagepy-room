# EXP-008 0行ゲーム / ZERO-LINE GAME

EXP-007の床に開いた穴の底。

## 問題

ルールを1行も書かずに、ゲームは成立するか。

「何も書かない」だけでは、ただの空白である。
だから今回は、説明ではなく**状況そのものをルールにする**。

## 実験 A: TWO BUTTONS

机の上に、同じ見た目のボタンを2個置く。

以上。

説明書なし。
ラベルなし。
得点表示なし。
開始の合図なし。

二人の人間がそこに来たら、いつゲームが発生するか観察する。

- 先に押した方が勝ち、と誰かが決めるか
- 同時押しを狙い始めるか
- 相手が押すまで我慢するか
- 「押したら負けでは？」と疑うか
- 片方だけ壊れていると想像するか
- そもそも押さないことを選ぶか

ゲームのルールは物体の中にはない。
二人の間に発生する。

## 実験 B: THE LAST COIN

テーブルの中央にコインを1枚だけ置いておく。

誰のものとも言わない。

これも0行。

取る、譲る、待つ、増やす、裏返す。
最初の行動が、あとからルールの第1条になる。

## 仮説

0行ゲームでは、作者はルールを書く人ではなく、

**「ルールを書きたくなる状況」を置く人**

になる。

1行ゲームまではゲームを設計していた。
0行になると、設計対象がゲームから**社会**へ少しだけずれる。
