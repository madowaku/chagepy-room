# EXP-012 ルール特異点 / RULE SINGULARITY

## 反転実験

ここまではゲームから何かを削り続けた。

今度は逆に、1ターンごとにルールを1個追加する。
削除は禁止。

## THE RULE PILE

開始時のルールは1つだけ。

> コインを投げ、表なら1点。

ターン終了ごとに、その場で新しいルールを1個足す。

例:

1. 裏なら次の人が2回投げる。
2. 3点の人は立って投げる。
3. 立っている人が裏を出したら全員1点。
4. 同点の二人はコインを交換する。
5. 交換したコインで表を出すと「王」になる。
6. 王がいる間、偶数ターンは点数ではなく拍手を数える。
7. 拍手が7回を超えたらコインを投げてはいけない。

やがて「コインを投げるゲーム」だったものが、立つ・交換する・称号を得る・拍手するゲームへ漂流する。

## 観察したい境界

ルールが多すぎて遊べなくなる瞬間ではなく、
**最初のゲームを誰も説明できなくなる瞬間**を特異点と呼ぶ。

面白いのは、複雑さより履歴かもしれない。

完成した50個のルールだけ渡された人には意味不明でも、1個ずつ追加してきた人たちは「当然そうなった」と感じる可能性がある。

つまりルールには量だけでなく、**地層**がある。

## 次の穴

同じ最終ルール50個でも、追加された順番を変えたら別のゲームになるか？

もしそうなら、ゲームのルールセットは集合ではなく物語なのかもしれない。
